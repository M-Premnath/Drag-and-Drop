# 🧲 Drag and Drop Items – HTML, CSS & JavaScript

This project showcases a **drag-and-drop UI** built using **HTML**, **CSS**, and **Vanilla JavaScript**, allowing users to move items between two containers.

## 📌 Features

- Interactive drag-and-drop experience

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## 🚀 How to Use

1. Visit the [Live Demo](https://m-premnath.github.io/Drag-and-Drop/)
2. Drag any item from one container and drop it into the other
3. Enjoy the smooth transition and interaction
